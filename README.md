# 暮灯镇 · Dusk Lantern Town

由朱家熠结合 AI 辅助开发的原创浏览器像素游戏原型。玩家在庄园与小镇中种植、探索、钓鱼、与居民互动，逐步推进心愿及防守/调查章节。

[在线游玩](https://dusk-lantern-town.qsgeorge897.chatgpt.site/?v=0.13.3)

## 此次公开版本

`0.13.3 · 封存库的回声`。从网站已保存的最新源代码版本整理，保留可运行的 HTML、CSS、未压缩的 JavaScript ES modules 与像素素材。该网站把可编辑静态源码存放在 `dist/`；这里的 `dist/` 不是仅有压缩 bundle 的构建产物。

## 玩法与实现

- Canvas 2D 地图、角色图集与像素物品表现。
- WASD/方向键移动、点击或 E 交互；触屏移动与交互按钮。
- 种植/采集/制作、库存与快捷栏、体力和时间系统。
- 小镇居民活动、叙事任务、区域及室内探索。
- 钓鱼、水渠防守及封存库调查相关模块。
- 浏览器本地自动存档，以及 JSON 存档导入/导出。

JavaScript ES modules、HTML、CSS，无框架运行依赖。主要模块包括 `rules.js`（状态与规则）、`world.js`（地图绘制）、`navigation.js`（移动）、`fishing.js`、`town.js`、`water.js`、`archive.js`，以及对应界面与素材模块。

## 本地运行

需要 Node.js 20+，无需安装依赖：

```sh
npm start
npm test
```

打开 `http://127.0.0.1:4174`。也可用任意静态服务器以 `dist/` 为网站根目录。请不要直接双击 HTML，因为 ES modules 需要 HTTP 环境。

测试检查 JavaScript 语法、相对模块引用及入口资源，不代表完整游戏剧情或所有浏览器兼容性已验证。
